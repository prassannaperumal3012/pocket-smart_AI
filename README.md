# PocketSmart AI

PocketSmart AI is a complete FastAPI + Jinja2 + SQLite
application implementing three AI-powered planning workflows:

1. Home Interior Budget Planner
2. Party Budget Planner
3. Jewelry Budget Planner

The application includes:

- FastAPI backend
- Jinja2 frontend
- Responsive CSS
- JavaScript frontend
- SQLite database
- User registration
- User login
- Logout
- JWT authentication
- Session information
- Recommendation history
- Gemini AI integration
- Multimodal jewelry image analysis
- Structured AI responses
- Local fallback recommendation engine
- Demo marketplace catalog
- Automated tests
